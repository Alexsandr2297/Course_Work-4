# Сервис управления рассылками

Веб-приложение на Django для создания и управления email-рассылками. Позволяет создавать рассылки, управлять получателями, отслеживать статистику и контролировать доступ пользователей.

## Возможности

- **Управление получателями**: CRUD для клиентов (email, ФИО, комментарий)
- **Управление сообщениями**: создание шаблонов писем (тема, тело)
- **Управление рассылками**: создание, редактирование, удаление, запуск
- **Отправка по требованию**: ручной запуск через интерфейс или командную строку
- **Логирование попыток**: сохранение статуса, ошибок, ответов сервера
- **Статистика**: количество успешных/неуспешных отправок
- **Аутентификация**: регистрация с подтверждением email, вход/выход, восстановление пароля
- **Роли**: пользователь (свои данные) и менеджер (просмотр всех)
- **Кеширование**: ускорение загрузки списков

## Технологии

- Python 3.14
- Django 6.0
- PostgreSQL
- Bootstrap 5
- Redis (опционально)
